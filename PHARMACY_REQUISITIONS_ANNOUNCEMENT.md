# 🎉 New Pharmacy Requisitions System - Team Announcement

## Overview
We're excited to announce the launch of our new **Pharmacy Requisitions Management System**! This comprehensive system streamlines the process of requesting, approving, and fulfilling pharmacy items for wards, ensuring better inventory control and preventing abuse.

---

## 🔄 How It Works

### The Workflow:
1. **Ward Staff** request items from the pharmacy store
2. **Pharmacy Head** reviews and approves/rejects requests
3. **Store Manager** fulfills approved requests (supports partial fulfillment)
4. Items are added to ward stock **only after fulfillment**
5. Ward staff can then debit items to clients for billing

---

## ✨ Key Features

### 1. **Duplicate Request Prevention**
- The system prevents creating duplicate requests for items that already have pending requisitions
- Staff are notified if an item has a pending request and must address the existing request first
- Option to cancel pending requests if needed

### 2. **Partial Fulfillment**
- Store Managers can partially fulfill requests when full quantities aren't available
- System tracks fulfilled vs. requested quantities for each item
- Remaining quantities can be fulfilled later

### 3. **Comprehensive Audit Trail**
- Complete history of all requisition actions (created, approved, rejected, fulfilled, cancelled)
- Tracks who performed each action and when
- Includes notes and reasons for transparency

### 4. **Smart Notifications**
- Real-time notifications for:
  - New requisition requests (Pharmacy Head & Store Manager)
  - Approval/rejection notifications (Ward Staff)
  - Fulfillment notifications (Ward Staff)
  - Cancellation notifications

### 5. **Advanced Filtering**
- Filter requisitions by:
  - Ward
  - Status (Pending, Approved, Rejected, Partially Fulfilled, Fulfilled)
  - **Date Range** (Start Date & End Date)
- Filters persist when performing actions (approve/reject/fulfill)
- Quick "Clear Filters" button for easy reset

### 6. **Request Cancellation**
- Ward staff can cancel their own pending requisitions
- Admins can cancel any pending requisition
- Cancellations are logged in the audit trail

### 7. **Ward Stock Management**
- View available stock for each ward
- Check stock levels before requesting items
- Pharmacy Head and Store Manager can check ward stock before approving/fulfilling

## 👥 Roles & Responsibilities

### **Ward Staff** (Nurses, Doctors, PAs)
- Create requisitions for items needed
- View requisition status and history
- Cancel pending requisitions
- View ward stock levels
- Debit items to clients (only after items are in ward stock)

### **Pharmacy Head**
- Review and approve/reject requisition requests
- Add optional rejection reasons/comments
- View all requisitions across all wards
- Check ward stock levels
- Access to all pharmacy management features

### **Store Manager**
- Fulfill approved requisitions
- Support partial fulfillment when needed
- View all requisitions and their status
- Check ward stock levels
- Access to all pharmacy management features (same as Pharmacy role)

## 📋 How to Use

### Creating a Requisition:
1. Navigate to **Pharmacy Requisitions** page
2. Click **"Create Requisition"** button
3. Select your ward
4. Add items by searching and selecting products
5. Enter quantities and optional notes
6. Submit the requisition

### Approving/Rejecting (Pharmacy Head):
1. View pending requisitions in the table
2. Click **"View"** to see full details
3. Click **"Approve"** or **"Reject"**
4. If rejecting, add an optional reason/comment

### Fulfilling (Store Manager):
1. View approved requisitions
2. Click **"Fulfill"** on an approved requisition
3. Enter fulfilled quantities for each item (can be partial)
4. Add fulfillment notes if needed
5. Submit - items will be added to ward stock

### Viewing Ward Stock:
1. Click **"View Ward Stock"** button
2. Select a ward to see all available stock
3. Check quantities before creating new requisitions

---

## 🔒 Important Rules

1. **Items can only be debited to clients AFTER they are in ward stock**
   - If ward stock is insufficient, you'll be prompted to request from pharmacy store first

2. **No duplicate pending requests**
   - If an item has a pending requisition, you must wait for it to be approved/rejected or cancel it before creating a new one

3. **Requisitions can only be cancelled if they are still pending**
   - Once approved or rejected, they cannot be cancelled

4. **Partial fulfillment is allowed**
   - Store Managers can fulfill part of a request and complete the rest later
