New hospital

Set the amount and the date/time the current license ends. Payment buys the next month from that moment — same idea as Starlink or Netflix.

If this is 31 Aug 2026, 11:59 PM, the next paid month is 1 Sep 12:00 AM through 30 Sep 11:59 PM. After they pay, the deadline moves forward automatically.

Renewal emails

The portal emails the IT manager 24 hours before the licence ends, then again 1 hour before. You can also send a reminder now.

Patch license

A patch is not a subscription payment and does not move the renewal deadline above. Set the coverage window, issue it, then download Patch license JSON. HMS Renew from portal will replace the current file if that window covers today. Paying later on the hospital dashboard also replaces it.
