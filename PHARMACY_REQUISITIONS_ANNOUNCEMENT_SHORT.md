# 🎉 New Pharmacy Requisitions System - Quick Update

Hi Team,

We've launched a new **Pharmacy Requisitions Management System** to improve inventory control and prevent abuse. Here's what you need to know:

## 🔄 New Workflow
**Ward Staff** → Request items → **Pharmacy Head** → Approve/Reject → **Store Manager** → Fulfill → Items added to ward stock → Can debit to clients

## ✨ Key Features
- ✅ **Duplicate Prevention**: Can't create duplicate requests for items already pending
- ✅ **Partial Fulfillment**: Store Managers can fulfill part of a request
- ✅ **Complete Audit Trail**: Full history of all actions
- ✅ **Smart Notifications**: Real-time alerts for requests, approvals, and fulfillments
- ✅ **Date Filtering**: Filter requisitions by date range (filters persist during actions)
- ✅ **Cancellation**: Ward staff can cancel their pending requisitions

## 👥 Your Role

**Ward Staff (Nurses, Doctors, PAs):**
- Create requisitions via "Create Requisition" button
- View your requisitions and their status
- Cancel pending requisitions if needed
- **Important**: Items can only be debited to clients AFTER they're in ward stock

**Pharmacy Head:**
- Review and approve/reject requisitions
- Add rejection reasons when needed
- View all requisitions across wards

**Store Manager:**
- Fulfill approved requisitions (supports partial fulfillment)
- Items are added to ward stock upon fulfillment
- Same access as Pharmacy role

## 📍 Where to Find It
Navigate to **Pharmacy Requisitions** in the main menu. You'll also see a notification bell for new requisition alerts.

## 🔒 Important Rule
**Items can only be debited to clients AFTER they are in ward stock.** If stock is insufficient, the system will prompt you to request from the pharmacy store first.

## 📊 Benefits
- Better inventory control
- Prevents abuse
- Complete transparency
- Streamlined workflow
